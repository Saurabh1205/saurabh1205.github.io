ENGINEERING STANDARDS

Architecture Philosophy

01

Clean Layer Separation

Strict boundaries between UI (Compose), Domain (Pure Kotlin Use Cases), and Data (Room/Retrofit Repositories) ensuring 100% testability and zero framework leaks.

02

Unidirectional Data Flow (UDF)

State is single-source-of-truth. UI emits User Intents, ViewModels execute use cases and emit immutable StateFlow objects back to the Compose UI layer.

03

Resilient Background Execution

Heavy sync jobs, telemetry tracking, and location logging are delegated to WorkManager to guarantee execution even through app kills and system reboots.
